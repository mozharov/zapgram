ZapGram превращает Telegram в приложение для Lightning-платежей: мгновенные tips в группах, инвойсы с QR-кодами, переводы между пользователями со скоростью сообщения и платный доступ к закрытым сообществам.

Без банка. Без границ. Только саты.

---

## Почему ZapGram?

| | |
|---|---|
| **Нативный Lightning** | Сатоши и BOLT11-инвойсы — без обёрток вокруг фиата. |
| **Без комиссий внутри Telegram** | Переводы между кошельками ZapGram бесплатны и мгновенны, как сообщения. |
| **Ключи — по желанию** | Храните саты во встроенном кошельке или подключите любой кошелёк с поддержкой NWC. |
| **Чаты, которые зарабатывают** | Монетизируйте закрытые группы и каналы: разовый доступ или ежемесячная подписка. |
| **Встроено в Telegram** | Tips через `/tip`, инвойсы в личке, заявки на вступление, которые оплачивают себя сами. |
| **Open source** | Смотрите код, поднимайте свой инстанс, участвуйте в разработке. |

## Возможности

### Lightning-кошелёк

Каждый пользователь получает Lightning-кошелёк в момент первого открытия бота.

- Баланс в сатоши в реальном времени
- **Получить** — создать инвойс (сумма + опциональный memo), поделиться QR / строкой BOLT11
- **Отправить** — оплатить любой Lightning-инвойс или перевести саты Telegram-пользователю `@username`
- Уведомления о входящих платежах и tips

Внутренние переводы между пользователями ZapGram проходят мгновенно и без сетевых комиссий — деньги двигаются как личное сообщение.

### Внешний кошелёк через NWC

Предпочитаете self-custody? Подключите **любой** Lightning-кошелёк с поддержкой [Nostr Wallet Connect](https://nwc.dev/) — например [Alby](https://getalby.com/invited-by/mozharov) или [Coinos](https://coinos.io).

- Привязка по URL вида `nostr+walletconnect://…`
- На экране кошелька видны **оба** баланса (ZapGram + NWC)
- Выбор, с какого кошелька уходят tips в группах
- Оплата подписок с NWC, если хватает баланса
- Отключение в любой момент

Внешний кошелёк остаётся под вашим контролем; ZapGram действует только в рамках выданных прав.

### Tips в группах и каналах

Добавьте бота в чат и отправляйте tips командой `/tip`:

| Команда | Что делает |
|---|---|
| `/tip` | 21 сат владельцу группы (или создателю канала — на посте) |
| `/tip 100` | Своя сумма владельцу |
| Ответ + `/tip` | Tip автору сообщения |
| Ответ + `/tip 1000` | Tip автору с указанной суммой |
| `/tip @user` | Tip конкретному пользователю (по умолчанию 21 сат) |
| `/tip 50 @user` | Tip пользователю с указанной суммой |

Сделайте бота админом (достаточно права удалять сообщения) — tips владельцу работают аккуратно, служебные сообщения не засоряют чат. В каналах tips в ответ на посты уходят создателю канала.

### Инвойсы: платить и принимать оплату

- **Создать** — сумма в сатах, опциональный memo → фото с QR и копируемый инвойс
- **Оплатить** — вставить или переслать `lnbc…` → проверить сумму, memo, комиссию, срок → подтвердить
- Для чужих инвойсов показывается fee reserve Lightning; уже оплаченные и просроченные обрабатываются безопасно
- Входящие платежи приходят уведомлением и обновляют баланс

### Платный доступ к закрытым чатам

Превратите закрытую группу или канал в сообщество с доступом за Lightning.

**Для владельцев**

1. Добавьте `@zap_gram_bot` с правами **приглашать пользователей** и **банить**
2. Откройте `/chats` → включите платный доступ
3. Задайте цену (саты), тип оплаты (**разовый** постоянный доступ или **ежемесячный**), при желании — кастомное сообщение при вступлении (RU + EN)

**Для участников**

1. Подайте заявку на вступление
2. Получите Lightning-инвойс (и кнопку быстрой оплаты, если хватает баланса ZapGram или NWC)
3. Оплатите → доступ выдаётся сразу

**Подписки**

- Ежемесячное продление может списываться автоматически с кошелька ZapGram
- Управление автопродлением и статусом — `/subscriptions`
- Ручные инвойсы на продление, если автопродление выключено или не хватает баланса
- Владельцы получают выплату автоматически (за вычетом небольшой комиссии платформы); дублирующие платежи возвращаются безопасно

## Быстрый старт (для пользователя)

1. Откройте **[@zap_gram_bot](https://t.me/zap_gram_bot)** → `/start`
2. Пополните кошелёк: **Получить** → создайте инвойс → оплатите с любого Lightning-кошелька
3. Отправьте tip в группе: `/tip 21 @username`
4. Или в личке: **Отправить** → пользователь / инвойс

Полезные команды:

| Команда | |
|---|---|
| `/wallet` | Баланс, получить, отправить |
| `/settings` | NWC, источник tips, справка по группам |
| `/chats` | Ваши платные группы и каналы |
| `/subscriptions` | Ваши подписки на платные чаты |
| `/help` | Bitcoin, Lightning, совместимые кошельки |

## Архитектура (для разработчиков)

Слои + вертикальные слайсы по фичам. Подробности: **[docs/architecture.md](./docs/architecture.md)**.

```
core → infra → modules → telegram / http / jobs
                ↑
            bootstrap (composition root)
```

Точка входа: `src/main.ts` → `createContainer()` → `createApp()` → старт / graceful shutdown.

### Стек

Bun, TypeScript, grammY, Elysia, Drizzle (SQLite), LNbits, Nostr Wallet Connect, pino, Biome.

**Lightning backend:** [Alby](https://getalby.com/invited-by/mozharov)

### Локальная разработка

```bash
# установка
bun install

# typecheck + lint + тесты
bun run ci

# локальный бот (нужен .env; HOST — публичный HTTPS URL)
bun run start:dev
```
